# Roadmap

## V2 Milestones

### M1: Core Usability
- Bottom bar restructure: Home, Scan, Tasks, Inventory
- Guided scan actions
- Multi-UOM quantity model
- Basic task queue (verify/dispatch)

### M2: Operational Control
- Movement ledger + timeline view
- Exceptions workflow (mismatch, wrong location, duplicate scan)
- Partial unpack/consume
- SLA aging widgets on Home

### M3: Advanced Capability
- Configurable workflow templates
- Conversion rules + validation engine
- Offline-first sync queue + conflict handling
- Shipment manifests + destination reconciliation
